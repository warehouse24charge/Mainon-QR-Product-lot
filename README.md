# 🏷️ Mainon QR-Product-Lot Studio

**เว็บแอปพลิเคชันสร้างและจัดหน้าสติกเกอร์ QR Code Serial Number สำหรับติดสินค้า (Product Lot & Serial Sticker Generator)**  
ออกแบบมาสำหรับงานผลิต, คลังสินค้า และควบคุมสต็อก สามารถจัดหน้ากระดาษ A4 หรือสติกเกอร์ไดคัทได้อย่างแม่นยำ พร้อมระบบบันทึกการตั้งค่าในเครื่อง (Local Storage) โดยไม่ต้องต่อ Database ภายนอก

---

## 📌 จุดเด่นของระบบ (Features)

### 1. 🔢 สร้าง Serial Number ได้หลากหลายวิธี
* **เลขรันอัตโนมัติ (Sequential / Auto-run):**
  * กำหนดเลขเริ่มต้น (เช่น `0673304866`)
  * กำหนดจำนวนดวงที่ต้องการสร้าง (เช่น 117 ดวงสำหรับ 1 แผ่น A4)
  * เติมเลข 0 ด้านหน้าอัตโนมัติ (Zero-padding เช่น 10 หลัก)
  * กำหนดคำนำหน้า (Prefix) / คำต่อท้าย (Suffix) และระยะก้าว (Step)
* **กรอกหรือวางรายการเอง (Manual Paste):** รองรับการคัดลอกรหัสสินค้าหลายร้อยรายการมาวางได้โดยตรง
* **นำเข้าจากไฟล์ Excel / CSV (Import):** อัปโหลดไฟล์จากระบบ ERP/POS และเลือกคอลัมน์ Serial ได้ทันที
* **สุ่มรหัสป้องกันการปลอมแปลง (Random Secure):** สุ่มรหัสตัวเลขหรือตัวอักษรเพื่อความปลอดภัย

### 2. 📐 จัดหน้ากระดาษและสติกเกอร์แม่นยำระดับมิลลิเมตร (mm)
* **เส้นชิดกันเป็นเส้นเดียว (Single-line Seamless Grid):** เส้นขอบระหว่างดวงติดกันเป็นเส้นเดียวตามค่าเริ่มต้น (Gap = 0 mm) เหมือนในแบบตัวอย่างกระดาษไดคัทจริง
* **มีแม่แบบพร้อมใช้ (Presets):**
  * **ต้นฉบับ (9 × 13 = 117 ดวง/แผ่น A4):** ขนาดและเลย์เอาต์ตรงตามตัวอย่างที่ระบุ
  * **สติกเกอร์ขนาดกลาง (5 × 10 = 50 ดวง/แผ่น A4)**
  * **สติกเกอร์มาตรฐาน (3 × 8 = 24 ดวง/แผ่น A4)**
  * **สติกเกอร์มินิ (10 × 15 = 150 ดวง/แผ่น A4)**
* **ปรับแต่งระยะได้อิสระ:**
  * กำหนดขนาดกระดาษ (A4, A3, Letter หรือ Custom mm)
  * ปรับระยะขอบหน้ากระดาษ (Top, Bottom, Left, Right Margin)
  * ปรับระยะห่างระหว่างดวง (Column Gap, Row Gap)
  * คำนวณขนาดกว้าง × สูงของดวงสติกเกอร์ให้อัตโนมัติแบบ Real-time

### 3. 🎨 ปรับแต่ง QR Code และสไตล์การแสดงผล
* **รูปแบบข้อมูลใน QR Code:** เลือกระหว่าง **รหัสข้อความล้วน (Plain Serial)** หรือ **ลิงก์ URL** (เช่น `https://mainon.com/verify?sn={SERIAL}`)
* **ความคมชัดระดับ Vector (SVG):** QR Code ใช้เทคโนโลยี SVG คมชัด ไม่แตกหรือเบลอแม้พิมพ์ในขนาดจิ๋ว
* **ระดับ Error Correction:** ปรับได้ (L, M, Q, H) เพื่อให้สแกนติดง่ายแม้อยู่ในสภาพแวดล้อมโรงงาน
* **ตัวอักษรและกรอบ:** ปรับขนาด Font, Font Family, ตำแหน่งตัวเลข (บน/ล่าง), เส้นกรอบแนวตัด (ทึบ/ประ/ซ่อน)

### 4. ☁️ บันทึกลง Cloudflare D1 Database (พร้อมชุดข้อมูลพิมพ์)
* **เชื่อมต่อ Cloudflare D1 (`24charge-db`) อัตโนมัติ:** บันทึกข้อมูลขึ้น Cloud ปลอดภัย และแชร์ใช้งานร่วมกันได้ทุกเครื่อง
* **บันทึก Data ที่จะใช้ปริ้นพ่วงกับ Template:** เมื่อกดบันทึก สามารถเลือกบันทึกทั้งการจัดหน้าและชุด Serial Numbers ทั้งหมดพ่วงไว้ด้วยกัน เมื่อโหลดแม่แบบ ข้อมูลทั้งหมดจะกลับมาพร้อมพิมพ์ทันที
* **โหมดคู่ Hybrid (Cloud + Local):** สามารถสลับบันทึกลง Cloudflare D1 หรือ Local Storage ในเครื่องได้ พร้อมปุ่มสำรองไฟล์ Backup JSON
* **บันทึกประวัติการพิมพ์ (Lot History / Audit Log):** ติดตามย้อนหลังได้ว่าเคยสร้าง Lot ใดไปแล้วบ้าง พร้อมปุ่มโหลดซ้ำ 1-Click

### 5. 🖨️ การพิมพ์และส่งออกข้อมูล (Print & Export)
* **สั่งพิมพ์ตรงผ่านเบราว์เซอร์ (Direct 1:1 Print):** คุมขนาดหน้ากระดาษด้วย CSS แม่นยำ
* **บันทึกเป็น PDF:** พิมพ์ออกเป็นไฟล์ PDF คุณภาพสูง
* **ดาวน์โหลด ZIP (ภาพ PNG แยกดวง):** รวมรูป QR Code ความละเอียดสูงแยกแต่ละ Serial เหมาะสำหรับส่งเข้าโปรแกรมพิมพ์บาร์โค้ด
* **ส่งออกรายการเป็น Excel (.xlsx) / CSV:** นำรายการ Serial ทั้งหมดไปบันทึกในระบบบัญชีหรือฐานข้อมูลต่อได้

## 🚀 วิธีการติดตั้งและรันใช้งาน (Getting Started)

### ความต้องการของระบบ
* [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป แนะนำ v20 หรือ v24)

### ขั้นตอนการรัน
1. เปิด Terminal / PowerShell ในโฟลเดอร์โปรเจกต์
2. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
3. เริ่มต้นรันเซิร์ฟเวอร์ Localhost:
   ```bash
   npm run dev
   ```
4. เปิดเบราว์เซอร์ไปที่:
   ```
   http://localhost:5173
   ```

### การ Build สำหรับนำไป Deploy บน Web Server / Hosting
```bash
npm run build
```
ไฟล์พร้อมใช้งานจะอยู่ในโฟลเดอร์ `dist/` สามารถนำไปวางบน Apache, Nginx, GitHub Pages หรือ Web Server ใดๆ ได้ทันทีโดยไม่ต้องรัน Node.js หลังบ้าน

## 🖨️ ข้อแนะนำในการสั่งพิมพ์ (Print Calibration Guide)

เพื่อให้ตำแหน่งและขนาดของสติกเกอร์ตรงกับกระดาษไดคัทจริง 100%:

1. เมื่อกดปุ่ม **"สั่งพิมพ์ / บันทึก PDF"** หน้าต่าง Print ของเบราว์เซอร์จะเปิดขึ้นมา
2. ในหน้าต่างตั้งค่าการพิมพ์ ให้ปรับค่าดังนี้:
   * **ปลายทาง (Destination):** เลือกเครื่องพิมพ์ของคุณ หรือ `Save as PDF`
   * **ขนาดกระดาษ (Paper size):** `A4`
   * **ระยะขอบ (Margins):** เลือกเป็น **"ไม่มี (None)"** หรือ *ต่ำสุด (Minimum)* ⚠️ *(สำคัญมาก เพื่อไม่ให้ระยะขอบเพี้ยน)*
   * **มาตราส่วน (Scale):** เลือก **"100% (ค่าเริ่มต้น / Default)"** ⚠️ *(ห้ามเลือก Fit to printable area)*
   * **ตัวเลือกเพิ่มเติม (Options):** ติ๊กถูกที่ **"กราฟิกพื้นหลัง (Background graphics)"**
